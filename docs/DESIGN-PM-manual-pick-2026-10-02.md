# 设计 · 产品经理视角：补封面「换封面」（2026-10-02 · v5 · 定稿）

> 角色：产品经理。姊妹篇：`DESIGN-UIUX-manual-pick-2026-10-02.md`。
> v5 变更（用户原话驱动）：「**我不要搞出太多的界面和入口，尽可能保持统一**」。
> ⇒ **v4 造多了**：在弹窗里新造"组列表 + 进组 + 搜索框"——那是在**重复主界面已有的能力**。v5 全部砍掉。
> **本文不写代码。**

---

## 一、v4 错在哪（自我纠正）

| v4 造的 | 其实主界面**已经有** |
|---|---|
| 弹窗内的"组列表"（按目录/演员分组） | 主界面的**网格 + 面包屑 + 双击进目录** |
| 弹窗内的"进组"二级视图 | 同上，就是"进目录" |
| 弹窗内的"搜索框" | 主界面的**搜索（还支持拼音首字母）** |
| 顶部新加的"范围"分段控件 | 没必要 —— 「更多」里加一项就够 |

⇒ **我又造了一堆界面和入口，而这套东西用户天天在用、就在主界面上。**

---

## 二、⭐ v5 的核心判断：挑选，就该发生在主界面

用户的真实动作是：**在主界面网格里看到一张糊封面 → 想把它换掉。**

而主界面恰好具备挑选所需的一切：

| 挑选需要 | 主界面是否有 |
|---|---|
| 看见每一张脸（缩略图） | ✅ 网格就是 |
| 按文件夹/演员组织 | ✅ **目录树就是**（他的盘 = `演员名/番号/视频+封面`） |
| 定位（找某个演员） | ✅ 搜索 + 面包屑 + 历史记录 |
| 按目录批量 | ✅ 目录格子天然是"一批" |

⇒ **不新增浏览界面。挑选叠加在主界面；抓取与写入复用现有「补封面」弹窗。**

---

## 三、信息架构（入口：**+1 项；界面：0 个**）

```
主界面（FileFinder，一切照旧）
├─ 工具条：[更多 ▾] [缓存记录] [搜索] [刷新]     ← **一个元素都不动**（铁律）
│    └─ 「更多」下拉：… 补封面 │ **换封面** ← 只在这里加一项
├─ 网格（一切照旧：双击打开 / 右键菜单 / 6 列）
│    └─ 进入「换封面」状态后：**单击 = 选中**（叠加，不改变双击）
├─ 网格下方状态条（`.scan-bar`，**已有先例**：进度与取消就住在这里）
│    └─ 换封面状态时显示：`已选 3 处 · 共 47 张 · [清除] [退出] [换封面…]`
└─ 现有补封面弹窗（全屏 n-modal）
     └─ **一字不改**，只是"清单"多了一种来源：主界面选出来的那批
```

**一个弹窗，两种输入**：
- 「补封面」= 让程序找出"没有封面的"（现有，不变）
- 「换封面」= 你自己在主界面挑出"要换的"（新）

两者最终走**同一条** 抓取 → 确认 → 写入 链路。

---

## 四、"按演员 / 按文件夹"如何被满足（不需要任何新机制）

| 用户想做的 | 在主界面上怎么做 |
|---|---|
| 只处理某个演员 | 搜索 / 进到该演员目录 → 选中里面的格子 |
| 整个演员一次性 | **选中那个演员目录格子** = 它下面**所有已有封面**（含子目录，从缓存算，零读盘） |
| 逐个细挑 | 进目录 → 单击要换的那几个 |
| 找某个番号 | 主界面搜索直接定位 |

⇒ **"按文件夹"就是主界面的目录树；"按演员"就是这个盘上目录名本身**
（证据：`server/index.ts` 的 `handleCover` 注释里把分类目录直接举例为
「**演员名目录**：`cover.jpg` + `TST-237/` + `TST-394/`」）。

⇒ 不需要抓"演员元数据"（那只有助手抓过的 87 个番号，会残缺），也不需要造分组界面。

---

## 五、被现有铁律挡住的三个做法（v4 曾想这么做，**全砍**）

| 想做的 | 为什么不行 |
|---|---|
| 模式态下把工具条换成"挑封面提示" | 工具条铁律：**"绝不消失、绝不换形，一个字都不随状态变"**（`index.vue:69-76`，用户批准的）⇒ 状态改放**网格下方的 `.scan-bar`**（已有先例） |
| 在工具条加一个"换封面"按钮 | 工具条**子元素个数恒定（4 个）**（同上）⇒ 入口放「更多」下拉里 |
| 在弹窗里再造目录导航/搜索 | 与主界面重复 ⇒ 砍掉 |

---

## 六、明确不做

| 不做 | 理由 |
|---|---|
| ❌ 任何自动判据 / 排序 / 自动预选 / 视觉标记"糊的" | 用户否过三次。**中性呈现** |
| ❌ 新的浏览界面 / 二级视图 / 分组列表 / 新搜索框 | 与主界面重复（§一） |
| ❌ 工具条加或换元素 | 铁律 |
| ❌ 删任何文件 | 覆盖 + 备份足够 |
| ❌ 手动输入路径 | 用户原话（2026-09-30） |
| ❌ 用"演员元数据"分组 | 数据只有 87 条，残缺；且不需要（§四） |
| ❌ 逐条确认弹窗 | PRD 已锁。"点格子"本身就是确认 |

---

## 七、写入（与前几版一致）

**一套逻辑通吃任何一张脸**：
1. 定位那张脸的真实文件名（封面卡：缓存里就有；有脸目录：写盘时探测一次）
2. **原图备份到系统盘**（`~/.file-finder/assistant/cover-backup/`）—— 兑现 PRD **D7「覆盖前先备份」**
3. 原子覆盖（tmp 在目标目录内 → rename；Windows 可覆盖，已实测）
4. 失效对应缓存

必须做（不是可选）：
- **`apply` 新增 `kind:'cover'` 分支**（现有 `buildGroups` 只有 `file`/`dir` 两支，`file` 支会无条件 `mkdir` + 搬视频 ⇒ 硬套会凭空建空目录且不覆盖）
- **`grab` 加"强制真抓"开关**（否则 hits 命中缓存直接返回旧 URL，重抓 = 拿回同一张，覆盖空转）

## 八、风险与诚实标注

| # | 风险 | 处理 |
|---|---|---|
| 1 | **改主界面**（核心界面） | 严格叠加：状态不存在时零行为，退出即完全恢复；**不碰双击/右键/搜索/面包屑/工具条** |
| 2 | 覆盖是破坏性操作 | 备份（D7）+ 新旧并排确认 + `apply.log` + 失败不回退既有项 |
| 3 | hits 短路 | 强制真抓开关 |
| 4 | `buildGroups` 无覆盖分支 | 新增 `kind:'cover'` |
| 5 | 有脸目录的脸名缓存拿不到 | 写盘时探测（access/readdir），代价极轻 |
| 6 | **"选中目录 = 它下面所有封面"的展开量可能很大** | 零读盘（走缓存）；选中后**先把数量显示出来**（`已选 3 处 · 共 47 张`），让人心里有数 |
| 7 | 跨盘标记 | 标记带 `serial + relPath`；处理时若跨盘，**按盘分批**（符合"串行、一次一块盘"） |
| 8 | 刷新（↻）后标记是否还在 | 标记按盘内相对路径存，**与网格刷新解耦**；退出状态时保留（再进还在），另给「清除」 |
| 9 | 没缓存的目录看不到缩略图 | 如实告知；目录仍可选中（数量按缓存算得到的部分） |

## 九、分阶段

### P0 · 完整闭环
1. 「更多」加「换封面」→ 进入叠加状态（网格可点选、状态条出现）
2. 单击选中/取消；**目录格子 = 整批**；角标显示选中
3. 状态条：`已选 N 处 · 共 M 张 · [清除][退出][换封面…]`
4. 后端：从缓存把"选中的位置"展开成条目清单（零读盘）+ 缩略图出口（`registerThumb` + `/thumb?k=`）
5. `apply` 新增 `kind:'cover'`（备份 + 原子覆盖 + 失效缓存）
6. `grab` 强制真抓开关
7. 现有弹窗接收这份清单，其余流程完全复用

### P1
8. 撤销（从备份目录还原这一批）
9. 显式读盘的「扫这一片」入口（要读盘，必须让人知道）
10. 键盘 roving

## 十、验收标准

| # | Given / When / Then |
|---|---|
| AC-1 | 进入「换封面」→ 网格可单击选中；**双击仍然是打开**（神圣特性不破） |
| AC-2 | 工具条**一个元素都没变**；状态显示在网格下方状态条 |
| AC-3 | 选中一个目录格子 → 显示"共 M 张"（从缓存算，**零读盘**，拔盘可跑通） |
| AC-4 | 退出状态 → 主界面**完全恢复原样**（单击不再选中、角标消失） |
| AC-5 | 刷新 / 切目录后，已选的标记**还在** |
| AC-6 | 点「换封面…」→ 现有弹窗打开、清单 = 所选项；抓取/被拦/预览/写入流程与现有**完全一致** |
| AC-7 | 写入 = 原文件被**覆盖**（名不变）+ **备份出现在系统盘** + **无文件被删** |
| AC-8 | 强制真抓生效（不被 hits 短路） |
| AC-9 | 「补封面」的现有行为**逐字不变** |
| AC-10 | `typecheck` 0 error |

---

## 十一、一句话总结

> **不造新界面 —— 主界面本来就有目录、缩略图、搜索，那就是挑封面的地方。**
> 「更多」里多一项「换封面」，网格上多一层"可点选"；处理还是那一个弹窗、那一条链路。
> 按演员、按文件夹，就是他自己盘上的目录。
