# 抽卡数据层 · 纯逻辑探针

> **只读**。跑法：`node docs/probes/lucky-draw/probe.cjs`（产物 `out.txt`，证据必须是 `.txt`）。
> 同 `playlist/` 的纪律：esbuild 打包**真源码**后断言 —— 验的代码和线上是同一份，不许手抄。

## 验什么（8 组 · 32 条）

| 组 | 对象 | 为什么必须测 |
|---|---|---|
| ① | `formatBytes` | 界面信息栏那行 `03 / 05 · C盘 · 2.4 GB`；`0 B` / `NaN` 不许显示出来 |
| ② | `drawPack` 数量与互不重复 | 抽 200 轮，每轮 5 张、`sig` 不重复、**入参不被洗乱**（池子是页面持有的快照，被洗乱会串到下一包） |
| ③ | 池子不足 | `< 5` 时少给，**不补齐、不重复**；`count 0` 给空 |
| ④ | 离线过滤 | 不含离线盘时，100 轮里一次都不许漏出离线 `serial` |
| ⑤ | 最近抽过优先排除 | 排除后仍要抽满；池子全被排除时必须放开补位（"记得太多导致抽不出"是绝不能有的） |
| ⑥ | `candidatesOf` 去重 | 去重维度是 **`sig`**（同一部作品换路径仍是同一张卡）；无 sig 的条目丢掉 |
| ⑦ | `cardOf` / `letterMapOf` | 离线盘的盘符**不许用**（拔盘那刻缓存里的旧盘符可能属于别人，贴错了比留空更误导）；`key` 与网格 `keyOf` 同形 |
| ⑧ | `rememberRecent` | 最多 3 包（15 个 sig）—— 池子小的用户会被自己的历史抽空 |

## 没验的（要靠真机）

- `/getAllCovers` 与 `/getDisks` 的实际返回（`usePool.ts` 顶层碰 `ipcRenderer`，node 里起不来）⇒ 靠"真机抽一包、拔一块盘再抽一包"覆盖
- `/getDisks` 失败时的降级（`onlineKnown === false` 强制包含离线）—— 只能真机拔/改端口复现
- 抽中的卡能不能真的拉起播放器（`openCover.ts`）

## 零读盘说明

`drawModel.ts` **零依赖、零 IO**。探针只做内存计算，不碰任何接口、不 stat 盘符、不碰移动硬盘。
