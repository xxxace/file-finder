# grid-cursor · 网格几何（纯逻辑）

```bash
node docs/probes/grid-cursor/run.mjs
```

**验什么**：网格的行结构怎么数出来、方向键怎么走。

**为什么必须探针而不能靠真机目视**：列数是**响应式**的（`--item-width` 在 5 个断点里是
`100%/6 → 20% → 33.33% → 50% → 100%`，即 6/5/3/2/1 列，`index.vue:1867` + `1940-1958`）。
目视只能验当前窗口那一种列数，**证伪不了**"3 列时按 ↓ 会不会跳错格"。

**手法**：esbuild 打包**真的** `src/views/FileFinder/gridGeometry.ts`（不复刻），
产物落 `os.tmpdir()` —— 探针**零读盘**、零写盘（除打包时读源码）。

**用例**：R1 五种列数 · R2 残行 · R3 浮点噪声容差 · R4 边界不环绕 · R5 残行上列号不变
· R6 退化输入 · R7 坐标是布局的函数 · R8 首次激活落视口第一行

**判据效力已验**：回退实现（去边界判断 + 容差改 0）⇒ **31 PASS / 10 FAIL**；恢复 ⇒ 41/0。
