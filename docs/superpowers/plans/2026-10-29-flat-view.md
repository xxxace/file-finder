# Flat 视图（平铺视图）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在文件浏览页面的根缓存目录下支持「正常视图」与「Flat 平铺视图」切换，Flat 视图跳过中间女优/父文件夹，纯在 NeDB 内存中将所有作品卡片摊开展现，零读盘秒级响应。

**Architecture:** 
1. NeDB 层：提供 `findSubtreeLeafItems` 纯内存检索当前盘符及路径前缀下所有非目录条目并按自然序排序去重。
2. Server 层：在 `/openFolder` 接口增加 `flat=true` 处理分支，根据只读锚点或在线盘符分别走 `toAnchor` 与 `toWire` 统一输出。
3. Vue 前端：在顶部工具栏增加平铺视图切换按钮，严格受限于根目录（`history.length === 1 && !playlistLevel`），切根或清空时自动复位。

**Tech Stack:** Vue 3, TypeScript, Naive UI, Node.js HTTP Server, @seald-io/nedb, esbuild, node:test

**Spec:** `docs/superpowers/specs/2026-10-29-flat-view-design.md`

## Global Constraints

- **减少对移动硬盘的读写**：Flat 模式完全依赖现有内存缓存，严禁进行物理递归扫盘，读盘次数为 0。
- **唯一出口契约**：所有下发前端的条目必须经过 `toWire()` / `toAnchor()`，确保缩略图、大图、完整路径处理一致。
- **组件规模与约束**：保持 `FileFinder/index.vue` 结构整洁，避免不必要的深度嵌套。
- **无测试框架限制**：使用 `docs/probes/` 下的 `node:test` 独立探针与 `npm run typecheck` 验证。

## Review Focus

1. 根目录为盘根（`relPath === ''`）时，前缀匹配必须覆盖该盘下所有子记录，不能漏掉。
2. 筛选必须严格排除目录（`it.type !== 'folder' && !it.isDirectory`），确保只有作品与封面卡片被摊开。
3. 离开根目录（如清空、换根）时，Flat 状态必须正确复位，不能带入其他目录。
4. 离线只读锚点（`#<serial>/...`）与在线实时盘符（`H:/...`）两条通道都要能正常平铺。
5. 搜索功能（`filterByName`）在 Flat 视图下必须对打散后的全部作品正常生效。

```ts
export async function findSubtreeLeafItems(
    serial: string,
    baseRel: string,
    mode: OpenMode = 'cover'
): Promise<FileInfo[]>
```
逻辑：
1. 查 NeDB 中 `serial` 和 `mode` 匹配的所有记录。
2. 过滤出 `relPath === baseRel` 以及 `relPath.startsWith(baseRel + '/')` 的记录（若 `baseRel === ''` 则全选）。
3. 收集所有 `doc.data` 中 `it.type !== 'folder' && !it.isDirectory` 的条目。
4. 按 `joinRel(it.dir, diskNameOf(it))` 去重。
5. 按名称自然序排序（`a.name.localeCompare(b.name, 'zh-Hans-CN', { numeric: true, sensitivity: 'base' })`）。

### Task 3: 前端视图切换按钮与 Flat 模式接入

**Files:**
- Modify: `src/views/FileFinder/index.vue`

**Interfaces:**
- Consumes: `/openFolder?flat=true` 接口

- [ ] **Step 1: 添加 Flat 状态与切换逻辑**

在 `src/views/FileFinder/index.vue` 中：
1. 增加 `const isFlatView = ref(false)`。
2. 增加 `const canToggleFlat = computed(() => history.value.length === 1 && !playlistLevel.value && !!currentPath.value)`。
3. 修改 `requestFolder` 与 `loadScreen`，支持将 `isFlatView.value` 传给 `/openFolder`（当 `isFlatView.value === true` 时加 `&flat=true`）。
4. 实现 `toggleFlatView`：
   - 切换 `isFlatView.value = !isFlatView.value`。
   - 重新触发当前屏刷新：`fetchFolder(cur.path, cur.mode, false)`。
5. 在 `setRoot` / `clearNav` 时重置 `isFlatView.value = false`。
6. 监听 `history.length`，若下钻深入子目录（`history.length > 1`）则自动恢复 `isFlatView.value = false`。

- [ ] **Step 2: 在顶部工具栏挂载切换按钮**

在 `toolbar`（刷新按钮前）增加平铺视图切换按钮：
```html
<n-tooltip>
    <template #trigger>
        <n-button size="small" :type="isFlatView ? 'primary' : 'default'"
            :disabled="scanning || !canToggleFlat" @click="toggleFlatView">
            <template #icon>
                <n-icon :component="AppsOutline" />
            </template>
        </n-button>
    </template>
    {{ isFlatView ? '当前为平铺视图（点击切回正常视图）' : (canToggleFlat ? '切换为平铺视图（摊开所有子目录作品）' : '仅在根缓存目录可开启平铺视图') }}
</n-tooltip>
```
