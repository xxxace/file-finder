## 一、从截图量出来的规范（实测，不是猜）

测量方法：原图 1485×925（125% 缩放，逻辑 1080×673），用 Pillow 按区域取众数色 + 扫描边界。
所有数字已换算成**逻辑 px**。证据等级：**实测**。

### 1.1 骨架尺寸

| 项 | 实测值 | 备注 |
|---|---|---|
| 左导航轨 | **64** 宽，整列 `#1F2022` | 与内容区不同色，靠色差分区，不用分割线 |
| 内容区背景 | `#18191C`（实测像素 `#17181A`，JPEG 偏色） | **不是纯黑**，避免光晕 |
| 顶栏高 | **68**（含 1px 底部分割） | 首页只有一行；收藏页多一行 44 的 chips 区 |
| 内容左内边距 | **31**（卡片左缘 95 − 轨 64） | 右内边距 30 |
| 卡片列数 / 间距 | 4 列，间距 **18**（实测 25px/1.375） | 1080 宽时卡片 **223** 宽 |
| 封面比例 | **16:9**（223×125） | 不是 16:10 |
| 封面 → 标题 | **8** | |
| 标题 | **15px / 行高 20 / 最多 2 行** | 行距实测 20 |
| 标题 → meta | **14** | meta 12px `#9499A0` |
| 搜索框 | **256×32**，圆角 8，底色 `#242527` | 无边框，靠底色区分 |
| 卡片封面圆角 | **6** | 收藏卡同为 6 |
| 封面角标 | 高 20，圆角 4，底 `rgba(0,0,0,.55)`，字号 12 | 左下=播放/弹幕，右下=时长 |

### 1.2 颜色（实测 + B 站公开色板对齐）

| token | 值 | 用途（我们的语义） |
|---|---|---|
| `--bg` | `#18191C` | 内容底 |
| `--surface` | `#1F2022` | 导航轨；比内容底**亮一档** |
| `--fill` | `#242527` | 搜索框 / 悬浮按钮 / hover 底 |
| `--line` | `rgba(255,255,255,.08)` | 分割线（B 站用 `#2F3134`） |
| `--text-1` | `#E3E5E7` | 标题 |
| `--text-2` | `#9499A0` | meta / 占位符 |
| `--text-3` | `#61666D` | 弱化 |
| `--pink` | `#FB7299`（深 `#E85B83`） | **选中态**：导航项、tab、收藏 |
| `--blue` | `#00AEEC`（深 `#0095CC`） | **可操作/焦点**：焦点环、链接、主按钮 |

**语义分工（关键）**：粉=「我在哪」，蓝=「能点哪」。现在的实现是蓝=焦点、绿=已选，与本方案冲突，见 §六。

### 1.3 组件 anatomy（B 站）

- **一级 tab**（我的收藏页）：16px，未选 `#9499A0`，选中 `#E3E5E7` + **2px 粉色下划线**（宽=文字宽，圆角 1）。
- **二级 chips**（收藏夹筛选）：14px，选中＝粉色文字 + 粉色图标，无底色；未选＝`#9499A0`。
- **次级按钮**（新建收藏夹/排序）：32 高，圆角 6，1px `#2F3134` 边框，透明底，hover 变 `#242527`。
- **收藏卡**：封面是 1 大 + 最多 3 小的拼图；左下角标「7个内容 · 公开」；右上「⋮」hover 才出现；卡片下方标题 15px 单行 + 「创建于2025-09-21」12px `#61666D`。
- **滚动条**：6px，thumb `#4A4B4D`，圆角 3。
- **右下悬浮圆钮**：48，`#242527`，hover 提亮（B 站是「刷新」）。
- **hover**：卡片只做**封面轻微上浮 + 标题变蓝**，不加边框、不加阴影。

### 1.4 明确**不抄**的

| B 站的东西 | 为什么不抄 |
|---|---|
| 弹幕 / 点赞 / 投币 / 关注 | 无对应数据，硬造就是假信息 |
| 无限流推荐 | 我们是「一层目录」的空间语义，不是信息流 |
| 纯黑 `#000` | B 站自己都不用；`#18191C` 更耐看 |
| 16px 大圆角（新版首页） | 桌面高密度场景用 6–8，圆角大会显得玩具化 |
| 首页的「分区 tab」 | 我们没有内容分区；硬塞一排 tab 只会多一层空点击 |

## 三、功能收纳（这次真正"动结构"的三件事）

### 3.1 工具条 5 个入口 → 拆成三层

现在 `header-bar` 一行里挤着：`选文件夹 | 面包屑 | 返回 | 更多▾ | 缓存记录 | 清单 | 搜索 | 刷新`。
导航区只有一半宽度，剩下全被按钮占住。

改造后：

```
左轨（常驻、64）   顶栏（44）                        次栏（32）
┌────┬──────────────────────────────────┬────────────────────────┐
│文件│ ← 面包屑 …              [搜索][↻][⋯] │ 盘条 C: D: E: …  12 项·3.4G │
│清单│                                  │                        │
│缓存│                                  │                        │
│    │                                  │                        │
│ ＋ │                                  │                        │
└────┴──────────────────────────────────┴────────────────────────┘
```

- 「缓存记录 / 清单」→ 左轨（**从按钮变页**）
- 「选文件夹」→ 左轨底部主按钮（bilibili 的「投稿」位）
- 「搜索 / 刷新 / 更多」→ 顶栏右侧，图标化，给面包屑腾出宽度
- 「换封面」→ 建议放次栏右侧（与 B 站「新建/排序」同位置），仍在「更多」里保底

### 3.2 两个弹窗 → 两个页

- 清单（`PlaylistShelfModal`）→ **清单页**：二级 chips（全部/默认/我创建的）+ 拼图卡网格 + 右上「新建清单」。
- 缓存（`HistoryTable`）→ **缓存页**：盘 chips + 概览 + 表格，内容几乎是现成的。

技术做法：**不引入 vue-router**。Shell 里一个 `active` 状态 + `<KeepAlive>`（保住文件页的导航栈、滚动位置、搜索词）。加路由是新增依赖 + 新增一层地址语义，收益为零。

### 3.3 盘条从「缓存面板私有」→「文件页公用」

盘条现在只在缓存面板里，导致「换一块盘」必须先开面板。搬到文件页次栏之后：切盘 = 一次点击，且**零读盘**（只是换根目录，走原有 `setRoot`）。

## 六、风险与技术约束（动手前必须认的三条）

### 6.1 网格 6 列算法是生命线，只能"接线"不能"换芯"

现状：`width: calc(100%/6 − 10px)` + 左右各 5px margin + 容器 `margin: 0 -5px`。
**保留这套算法**（margin 撑间距 + 宽度补偿），只改 `--item-gap`（10 → 16）与容器外扩（= gap/2）。
**5/3/2/1 四档断点已按主人裁决删除**，`--item-width` 只剩 `100%/6` —— 任何窗口都是 6 列。

### 6.2 ⚠️ 卡片高度：从「视口函数」改成「宽度函数」，必须实测

现状 `--item-height: 1.5rem !important`（`1rem = 视口宽/10`），卡片高度是**视口**的函数。
改成 16:9 封面后，高度变成**卡片宽度**的函数，整套 `!important` 要拆掉。

这里有一个真风险：`gridGeometry.groupRows()` 用 `offsetTop` 判断"是不是同一行"，**依赖同行格子等高**。
如果标题一行/两行不定高，同一行的格子会矮一截 ⇒ 行被劈开 ⇒ 方向键横着跳（2026-10-04 已经踩过一次）。

⇒ **标题区必须定高**（永远占两行的高度，单行标题也留白），并用 `docs/probes/grid-cursor/` + 真机双向验证。
证据等级：**推理**（机制清楚，未实测），所以单独列为本批的验收项。

### 6.3 禁令照旧（一条都不碰）

- `.header-bar { flex-wrap: nowrap }`、`.header-bar .n-input { width:200px }`、`.toolbar` 不随状态变
- 不用 `n-space` 装会增减的子元素（naive-ui 2.45.3 重复 key）
- 不删 `flexible.ts`
- 双击打开、单击选格、右键菜单、`S/F5/D`、拼音搜索、面包屑折叠、返回恢复滚动+焦点、封面收敛、空状态一行字
- 缓存层永不自动删；本方案**零新增读盘**
