## 五、关键技术点（会踩的坑）

1. **6 列恒定**：删掉 `@media` 里 `--item-width: 20%/33.33%/50%/100%` 四条；`--item-width` 只留 `calc(100%/6)`。
   代价写清楚：1024 宽时卡片 ≈135px，标题两行约 16 字。若不接受，把窗口 `minWidth` 提到 1200（一行改动，待定）。
2. **卡片高度改由宽度推导**：`aspect-ratio: 16/9` + 定高文字块。`flexible.ts` **保留**（`1rem` 还被别处消费），只断掉网格对 `--item-height` 的依赖。
3. **KeepAlive 下的快捷键**：`useGridCursor` 与 `S/F5/D` 都挂在 `window` 上；页面被缓存后监听仍在 ⇒ 必须加 `active` 门，否则在清单页按 `S` 会去改文件页的搜索词。
4. **跨页跳转**：清单/缓存不再住在文件页内部，`openHistory` / `openPlaylistScreen` 的调用点要从「同组件直调」改成「Shell 转发」。**这是本次唯一真正动到状态流的地方**，单独验收。
5. **主题 token 命名**：`--ff-bg` / `--ff-surface` / `--ff-fill` / `--ff-line` / `--ff-text-1..3` / `--ff-pink` / `--ff-blue`。naive-ui 内部仍用 `--n-*`，两者不互相覆盖。
6. **盘条数据**：走 `/getDisks`（进程内缓存，**不扫盘**）+ `ff-disks-changed` 后重取。新插的盘在面板刷新前不会出现——这是既有取舍，不新增。
7. **搜索框宽度**：`.header-bar .n-input { width: 200px }` 这条守卫**不能删**，只改数值（320）。删了 naive 的 `width:100%` 会把头部撑成三行（2026-09-24 事故）。
