## 修：预览停住后不再变清晰（业主报回归）
- 根因：11-10 把预览 `src-list` 改成快照 `previewSrcList` 时剪断了升级链——旧实现绑实时 computed，`sharpKey` 一变 naive 自动换大图地址；快照只在「打开 / 开着时 fileList 变」重拍，`sharpKey` 变化没人通知 ⇒ 停住升级后 naive 手里还是缩略图地址 ⇒ 永远糊。
- 修：`usePreview.ts` 加 `watch(sharpKey, k => { if (k && previewOpenState.value) snapshotSrcList(); })`。只在升到**非空** sharpKey 且开着时重拍：归零不拍（openPreview 本来就拍过，重拍白扫）；关着不拍（快照化初衷=关着不扫整屏）；「关只改开不开、不清快照」的不变量不动。
- ⚠️ 教训：**把某个 computed/绑定改成快照时，要把原来靠响应式"自动到达"消费者的每条链数一遍**——sharpKey→src-list 这条被漏了。与「关预览清 src-list 裂图」「一条 URL 多处消费」是同族坑。
- typecheck 0 error；渲染层改动，dev 热更即可。待业主目视：翻页停下 0.3s 后应换清晰大图。
