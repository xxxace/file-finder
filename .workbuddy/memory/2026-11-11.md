## 预览工具条：文件名/序号 改交叉淡出（原上浮 5px）
- 原实现 `{opacity:0, transform:'translateY(5px)'}` + `--ff-ease-enter`（过冲 1.28），业主「我要原地不动的」⇒ 先改纯淡入，再看演示后选定**交叉淡出**。
- 关键难点：**naive 已把 DOM patch 成新内容，旧文字拿不到** ⇒ 必须在 `previewToolbar` 的 **render 阶段**（此时 DOM 还是旧内容，与量 `lastBarW` 同一时刻）`cloneNode('.ptb-info')` 存成幽灵，rAF 里再盖回去淡出。
- ⚠️ 幽灵必须插在 **`.ptb-info` 内部**（`left/top:0`），不能定位在工具栏上：工具条是 `justify-content:flex-end`，条变宽时整块信息段**左移** —— 幽灵停在旧坐标会和新字朝不同方向走，正好毁掉"原地"。
- ⚠️ 幽灵宽度**钉死旧值**（不能让父级带）：否则旧字按新宽重算省略号，闪出用户没见过的文字。⚠️ `.ptb-info` 是 content-box 而 JS 传的是 GBCR 宽（border-box）⇒ `.ptb-ghost` 必须显式 `box-sizing:border-box`，否则宽出 20px padding。
- 节奏：旧字 0~110ms 淡出，新字 delay 70 淡入（合 180ms，重叠只 40ms）。**不用 VT 那种 50/50 linear**：那是给图像对图像的，换成人眼读的文字，50/50 就是重影，12px 小字上尤甚。⚠️ 新字淡入必须 `fill:'backwards'`，否则 delay 那 70ms 里会先露出新字。
- `preview-bar.css`：`.ptb-info` 加 `position:relative`；新增 `.ptb-ghost`。typecheck 0 / vite build 通过。
