## 预览图"点图外关闭"—— 调研完、被用户叫停，**产品代码零改动**

用户问：「是否可以点击图片外的范围就关闭预览？现在要点击关闭按钮才能关闭」

### 我做了什么（全部落在 `docs/probes/preview-fill/`）
把根因、四个候选方案、A/B 对照全跑通了（真 Electron offscreen，视口 1903×1063）：

- **根因**：naive-ui 的"点图外关闭"是靠 overlay 接住点击。上一版把预览 img 的元素盒撑满视口后，
  **图内容与盒子之间的留白也归 img 吃点击**（大图左右各 162px、竖图左右各 764px、宽银幕上下各 360px），
  那部分从 overlay 手里被拿走 → 点它不再关闭。
- **`stretchClick`（stretch + 坐标判定）实测通过**：同一探测点，无判定 `closed:false` / 有判定 `closed:true`；
  点图内容正中两种方案都 `closed:false`（不误关）。A/B 对照成立。
- **`fit` / `fit48`（盒子贴合图 + 放大边距）已排除**：对**比视口更宽**的图失效 ——
  `width:auto; height:100%` 只在"高度受限"时保持比例，宽银幕图宽被 `max-width` 钳后**高度不重算**，
  假空白 360px 又回来了（`boxEqualsContent:false`）。

### 结果：用户裁定不采用
原话：「**算了 如果要算这么多东西就不要搞了**」

→ `src/views/FileFinder/index.vue` **一行未动**，保持 09-27 的"打开即撑满"
（`previewedImgProps = { style: { width:'100%', height:'100%', objectFit:'contain' } }`）。
探针里保留 `stretchClick` 的代码与 `out.log` 只作证据，README 顶部已写明"未采用、勿误读"。

### ⚠️ 教训（本轮最值钱的一条）
**诉求明确、但实现有成本梯度时，先给成本阶梯，再动手。**
这次的诉求其实有两条路：
- **一行版**（`pointer-events:none`）：点任何位置都关（含点图片本身），够用大部分场景
- **约 20 行版**（坐标判定）：精确区分图内/图外

我直接端上了 20 行那版的设计，他只看到"要算这么多东西"就否掉了 —— **而一行版覆盖同一诉求的绝大部分**。
正确做法：**先摆出"一行能拿到什么 / 多花 20 行能多拿到什么"，让他选**，而不是替他把最完整的那版做完再汇报。

补充事实：naive-ui 预览面板**没有任何外部可用的 close API**（只能点它自己的 overlay / ✕ / Esc），
所以"关闭"这条路要么走 overlay 的 DOM click，要么用一行版让事件自己穿透过去 —— 没有第三条。

### v2 打磨（用户四问：用上大小 / 有遗漏吗 / 三神技 / 交叉验证）

#### Q1 结论：**能用上文件大小，数据早就在库里**
- `FileInfo.size` 一直存着；**收敛条目的 size = 该子目录所有文件之和**（`server/index.ts:347-398`，`size += stat.size`）。
- 实测：213 条里 **210 条**能算出量；单层最大 **492.55 GB**；全库 **3.35 TB**；内存聚合一次 **0.07 ms**（零额外磁盘 I/O）。
- **双算证伪（3 轮探针收紧）**：① 有父路径 208/213（只是结构）→ ② 父自身字节>0 有 102 条（必要不充分）→
  ③ 精确判据「父层非 folder 条目名 ∈ 同名子记录名」= **0 条**；反证 208 对配对**全部是 folder 条目（size 0）**。
  - 结构性原因：**收敛要求子目录没有子目录，而被收敛的目录永远不会产生独立记录**（双击封面条目 = 打开里面的视频，不是进目录）。
  - ⚠️ 不是结构性保证：用「选择文件夹」手工选一个已被收敛的子目录 → 就有了独立记录 → 盘级会虚高。
- **裁决**：做**行级「大小」列 + 按大小排序**；**不做**盘级/全库总量（快照 + 有理论双算 → 会误导）。
  文档里落了「库 81.7 MB ↔ 省下 3.35 TB 重读 = **1:43000**」这个"缓存值不值"的答案。
- **发现 `parseSize` 的 TB 截断**：`src/utils/index.ts:3` 是 `gb = bytes/1G % 1024` → 1.83 TB 渲染成 `850.xxGB`，2 TB 渲染成 `0.00GB`。**静默输出错误数字**，一行必修。
