# 脱敏自检（这个仓库入库前必跑）

## 为什么

这是**脱敏仓库**（远端 `github.com/xxxace/file-finder`）。铁律：
任何入库文本（源码注释 / `docs/` / `.workbuddy/memory/` / 探针 / 夹具）**不许**出现
真实番号、真实演员名、真实作品名、真机目录与文件名、纯数字站点流水号、盘序列号、用户名。

先在的判定见 `docs/` 里的历史提交 `fff69a0`（"脱敏并提交"）。**改工作区只能让"以后"干净，历史里的还在** ——
所以命中时除了换占位，还要提醒用户"这需要决定是否清历史"。

## 怎么跑（只审本次要提交的那批，别全仓扫）

1. 看这批是哪些文件：`git status --porcelain=v1`
2. 逐个扫可疑形态：
   - **8 位大写十六进制**（盘序列号形态）
   - **中日文姓名形态**（2–4 字 + 常见姓氏 / 片假名）
   - **常见真机目录名**（注意：`新建文件夹`、`videos`、`download`、`temp` 这类也是真机名）
3. 项目既有的番号自检：`git grep -nE '[A-Z]{2,6}[0-9]{0,3}-[0-9]{3,5}'`
4. 命中的**一律换成占位**再提交

## ⚠️ 两个坑（都踩过）

1. **别用通用 hex 当模式**：`\b[0-9A-F]{8}\b` 会把 SVG 色值、`Cache-Control: max-age=31536000`
   一起算进去，扫出来一堆假命中（本轮就误报过 30 个文件）。
   → 用**确切的真实标识**当模式（从 `disks.json` 拿序列号、从探针输出拿姓名），或扫完人工筛。
2. **写"我脱敏了"的复盘日志时最容易复发** —— 别把原值当例子抄一遍，
   只写**类别与占位风格**（例如"真实演员名 → 示例演员X"）。

## 占位风格（沿用 `fff69a0`，别新发明）

| 类别 | 占位 |
|---|---|
| 番号 | `TST-xxx`；要保留格式族时用 `FC2-PPV-1000001` / `200GANA-1001` / `1PONDO-100001` |
| 演员名 | `示例演员A` … `示例演员H` |
| 作品 / 系列名 | `示例作品标题` |
| 片商 | `示例片商` |
| 盘序列号 | `AAAA1111` / `BBBB2222` / `CCCC3333` |
| 真机目录名 | `示例目录` / `示例分类目录` |
| 路径 | `D:/sample/videos/…` |

## 交付口径

报「**哪些文件命中、几处、属于哪一类**」，**不要复述真实值本身**。
