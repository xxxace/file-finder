# 桌面端界面重构 · 四层决策流程

## 用途

把"做得更高级"翻译成**可校验的层次决策**：先定骨架，再定视觉，再定控件，最后才配动效。
顺序不能反 —— 先上动效是"给没搭好结构的东西贴装饰"，越贴越乱。

参考系是**具体产品**（Codex / WorkBuddy / Apple 桌面端），不是"高级感"这种形容词。

## 何时使用

- 把参考站/参考产品的观感搬到自己的界面
- 现有界面"能用但不像产品"
- 动效做完但"味道不对"/"看着难受"
- 新建工具类、后台类、工作台类界面

## 开工前先问三件事（缺一件就别动手）

1. **这个界面的主任务是什么**（一句话，只允许一个动词）
2. **信息分几层**（通常三层：我是谁 / 我要看什么 / 我能做什么）
3. **有没有必须保留的既有便捷**（老用户的肌肉记忆不能重排）

## 四层流程

### 第一层 · 骨架（先定尺寸，不碰颜色）

| 部位 | 高度 | 规矩 |
|---|---|---|
| 顶栏 | 44px | 单行；左 = 身份，中 = 上下文，右 = 工具 |
| 内容区 | 自适应 | **唯一的滚动容器**；padding 20 / 24 |
| 底栏 | 52px | 常驻；主操作永远在右下 |
| 列表行 | 64px | 头像 48 + 上下 8 |
| 卡片 | — | 定比例（如 3:2），**绝不由内容撑高** |

判据：三个高度写死之后，缩窗口时**只有内容区变**，顶栏底栏不动。做不到就是骨架没定。

### 第二层 · 视觉四件套（明度 / 字阶 / 圆角 / 间距）

**明度三档**：`canvas` < `panel` < `raised`。深色靠明度分层、**不加投影**（深底上的投影只会脏）；
浅色靠投影 + 一档描边，因为浅底明度差不够。

**字阶四档**：15 标题 / 13 正文 / 12 辅助 / 11 眉标。**只用 400 和 500 两个字重**
（中文没有 600 的字形，写了也是假层级）。

**圆角三档且同心**：卡片 10 / 控件 8 / 小标 6。同心 = 内层圆角 = 外层 − 间距，
否则转折处会挤出一个尖角。

**间距只用 4 的倍数**：8 / 12 / 16，三层递减：组间 16 > 组内 12 > 元素间 8。

### 第三层 · 控件（统一到 3 种形态，别发明第 4 种）

| 形态 | 长相 | 用在哪 |
|---|---|---|
| primary | 反色（深色下白底黑字） | 一屏最多一个 |
| default | 比面板亮一档 | 次要动作 |
| ghost | 透明，悬停才出现底 | 工具条、行内 |

**强调色只允许出现在三处**：选中、焦点、悬浮。
主按钮涂成强调色 = 立刻变成第四处，整屏就花了。

状态色：绿 = 成功，黄 = 警告（未命中算警告，不算错误），红 = 失败。

### 第四层 · 动效预算（该有才上，通常 6 处以内）

先数**这个界面真正发生了几件事**，一件事最多配一个动效。
决策表见 `references/motion.md`。三条铁律：

1. **同一处状态变化用同一个节点形变**，不要拆两个节点交叉淡入
2. **进出不对称**：进场慢（200ms）、退场快（90ms）
3. **hover 只许变色，不许位移** —— 密集清单里会抖

## 资产（可直接拷进新项目）

| 文件 | 是什么 |
|---|---|
| `assets/tokens.css` | 三层 token 全套（明暗两套、字阶、圆角、间距、时长、曲线、光效色）。**色值只在这一份里出现** |
| `assets/panel-skin.css` | 面板皮肤：壳 / 工具条 / 底栏 / 卡片 / 列表行 / 骨架 / 空态。900 行，含每条规则的"为什么" |
| `assets/WorkbenchShell.vue` | 骨架组件：44px 顶栏（身份 / 上下文 / 工具三槽）+ 内容区 + 底栏插槽 |
| `assets/TaskDock.vue` | 底栏组件：空闲/运行/暂停/完成四态**同节点形变**，进度线走 `transform` 不占布局 |

用法：拷 `tokens.css` 先进新项目的样式入口，再把 `panel-skin.css` 与两个组件一起搬，
最后**全局替换前缀**（`--ff-` → 新前缀，`.ffw-` → 新前缀）。

## 交付前自检（十条，缺一条别交付）

1. 三个高度（44 / 52 / 64）写死了吗？缩窗口只有内容区变？
2. 字重只有 400 / 500？强调色只出现在三处？
3. 所有 hover 只变色、没有位移或抬升？
4. 列表入场有延迟阶梯且**封顶**了吗？（不封顶 500 项会拖到 9 秒）
5. 进度类动画**没有缓动**吗？（缓动会骗人，前快后慢像卡住）
6. 空态、加载态、错误态三样都画了吗？
7. 主操作唯一且落在右下？
8. 有没有"点了看不出反应"的按钮？（控制类请求失败必须报出来）
9. 深色下所有文字实测过对比度吗？（灰色辅助文字在深底上很容易读成"禁用"）
10. 关掉动效（`prefers-reduced-motion`）之后，界面还能表达同样的信息吗？

## 注意

- 资产里的类名前缀（`--ff-` / `.ffw-`）是来源项目的，**采纳时统一改名**，别把项目缩写带进新项目。
- 这套参数来自 1280×860 的桌面工具窗口。改成网页或大屏时，只有**间距和卡片尺寸**需要放大，
  字阶和圆角**不要**跟着放大（一放大会立刻变"土"）。
