# 十个坑 · 全是"看起来对，就是不生效"

动手前扫一遍。每条都写明**判据**，别靠感觉。

## 1. 动效"变形"了，其实是布局在动

**症状**：遮罩/光带被压扁，观感"先上后下"。
**真因**：某条状态栏挂上时用 `grid-template-rows: 1fr → 0fr` 从 0 长到 40px，
这 40px 是**从内容区扣的** ⇒ 里面的 `inset:0` 遮罩跟着变矮 ⇒ 位图被 CSS 压扁，
同时状态栏自己向下展开。两个动作在同一个 200ms 里发生。
**判据**：动效"变形"时**先怀疑布局在动**，别去改缓动曲线。
**修法**：动效期间不渲染那条会改变高度的东西；canvas 自己上 `ResizeObserver`。

## 2. `box-sizing` 从来没有全局设过

**症状**：`width:100%` 的输入框比它的栅格列**宽 18px**，压住右边那一列。
**真因**：项目里 `grep box-sizing` 零命中，`width:100% + padding 8×2 + border 1×2 = +18px`。
**判据**：任何 `width:100%` + 带内边距/边框的元素，先确认祖先链上有 `border-box`。
**修法**：作用域内加 `.your-shell, .your-shell * { box-sizing: border-box }`。
**不要**全局加 —— 老界面从没按 border-box 适配过，全局加会把所有"宽度+内边距"的元素改小一圈。

## 3. 自绘 `<button>` 的图标不居中

**症状**：18px 的勾选框，勾整体右偏 3.5px（实测）。
**真因**：`<button>` 的 UA 默认是 `padding: 1px 6px`，配 `width:18px` 后内容盒只剩 4px，
`place-items:center` 再也居中不了。
**判据**：自绘 button 只要写了固定 `width/height` + `place-items:center`，**必须同时写 `padding: 0`**。

## 4. 队列闸门写在"队列空没空"之前 → 死锁

**症状**：底栏永远停在「已暂停 1 / 1」，明明早就跑完了。
**真因**：
```
for (;;) { await gate.wait(); const i = next++; if (i >= n) return; ... }
```
最后一条已经取走时点暂停，worker 挂在 `wait()` 上永不返回 ⇒ `Promise.all` 不 resolve。
**判据**：任何「闸门 + 共享下标」的 worker，顺序必须是
`if (next >= n) return;` → `await gate.wait();` → `if (next >= n) return;`（第二道防多个 worker 同时被放行）。

## 5. 控制类请求失败被静默吞掉

**症状**：按钮"点了没反应"，用户只能得出"这按钮坏了"。
**真因**：`pause/stop` 里 `catch {}` 什么都不做。
**判据**：**任何控制请求（暂停/终止/写入/删除）失败必须有可见反馈**。
另外：表示"进行中"的状态位（如 `acting`）必须在 `finally` 里清 ——
卡在 `'stop'` 会让整组按钮从此点不动。

## 6. 把"还活着"当成"正在跑"

**症状**：暂停之后，未处理项的加载动画还在转。
**真因**：`isLive = status === 'running' || status === 'paused'`，被拿去当"正在抓"用了。
**判据**：**"是否还要发新请求"和"是否还在动"是两个判断**，别共用一个布尔。

## 7. naive-ui（或任何封装组件）的底色画在子节点上

**症状**：给 `.n-base-selection` 设背景色，怎么都不生效。
**真因**：底色实际画在 `.n-base-selection-label` 上，外层是透明的。
**判据**：改第三方组件样式前，先用 `getComputedStyle` **读出真值**，确认生效在哪个节点上。
**验证**：改完再读一次 computed style，别只看截图"感觉变了"。

## 8. 主题覆盖作用域失控

**改组件皮肤**用组件自己的 `:theme-overrides`（局部），**不要**改全局主题 ——
全局改会同时影响应用里所有同类控件，而你可能只想改一个工具条。

## 9. 一条动画里塞了两颗时钟

**症状**：收尾补播时"闪一下"，看不出扫过。
**真因**：`const t = p * 5.2` —— 进度 `p` 同时当时钟用。收尾要把 `p` 从当前位置跳到扫走起点，
`p` 一动，横向摆动/呼吸/粒子相位全部跟着跳。
**判据**：**位置参数和时钟参数必须是两个变量**。位置可以跳（跳到视觉上等价的区间），时钟必须匀速。

## 10. 入场动画不封顶 / 用错 fill-mode

**症状**：500 项列表入场拖到 9 秒；或者首屏一片空白。
**真因**：`animation-delay: i * 18ms` 不封顶；`animation-fill-mode: both` 在延迟期间元素是 **opacity 0**。
**判据**：延迟阶梯必须 `min(i, 14) * 24ms` 之类**封顶**，且封顶值要覆盖一屏可见项。

## 附：两个"看起来无关"的

- **列表 key 不能只用文件名**：同一层两个目录都叫 `cover.jpg` 会生成重复 key，
  Vue 复用错实例 ⇒ 内容串到别的行。
- **进度类动画不要缓动**：缓动会让"前快后慢"看起来像卡住。线性才对得上真实进度。
